# WBS Tool

軽量で高性能なWeb Based Work Breakdown Structure & Agile Project Management ツール

## 🌐 公開ページ

**https://j-komatsu.github.io/wbs-tool/**

ブラウザでアクセスするだけで、すぐに使えます！

## 概要

WBS Toolは、完全にブラウザ上で動作する静的Webアプリケーションです。サーバー不要で、ローカルストレージを活用してプロジェクト管理を行えます。

### 主な特徴

- 📊 **WBS & ガントチャート**: 階層的なタスク管理とビジュアルなスケジュール表示
- ⚡ **イナズマ線**: 進捗状況を一目で把握
- 🏃 **アジャイル/スクラム対応**: スプリント、バックログ、ストーリーポイント管理
- 📋 **カンバンボード**: タスクをドラッグ&ドロップで直感的に管理
- 📈 **豊富なチャート**: バーンダウン、ステータス分布、担当者別負荷など
- 📄 **自動レポート生成**: 進捗レポートをPDF形式で出力
- 💾 **ローカルストレージ**: サーバー不要、データは全てブラウザに保存
- 📤 **インポート/エクスポート**: JSON形式に対応
- 🎨 **カスタマイズ可能**: ダークモード、自動バックアップ設定など

## クイックスタート

### オンラインで使う（推奨）

**https://j-komatsu.github.io/wbs-tool/** にアクセスするだけ！

### ローカルで使う

1. リポジトリをクローン
```bash
git clone https://github.com/j-komatsu/wbs-tool.git
cd wbs-tool
```

2. ブラウザで `index.html` を開く
```bash
# シンプルなHTTPサーバーを起動（推奨）
npx http-server -p 8080
# または
python -m http.server 8080
```

3. ブラウザで `http://localhost:8080` にアクセス

> **Note**: ファイルプロトコル（`file://`）でも動作しますが、一部機能が制限される場合があります。HTTPサーバー経由の利用を推奨します。

## 使い方

### 基本操作

1. **新規プロジェクト作成**: ヘッダーの「+」ボタンをクリック
2. **新規タスク作成**: 「📝 新規タスク」ボタンをクリック
3. **タスク編集**: タスク行をクリックして編集
4. **階層化**: インデントボタンで親子関係を設定
5. **ビュー切り替え**: ヘッダーのタブで、ガントチャート/カンバン/バックログ/ダッシュボード/レポートを切り替え

### スプリント管理

1. **スプリント作成**: バックログビューから「新規スプリント」
2. **タスク追加**: タスクを編集してスプリントを選択
3. **進捗確認**: ダッシュボードでバーンダウンチャートを確認

### データエクスポート

- **JSON**: 完全なプロジェクトデータ（バックアップ用）
  - ヘッダーの「📤 エクスポート」ボタンからダウンロード
- **レポート**: PDF形式の進捗レポート
  - レポートビューから「レポート生成」ボタンをクリック

### サンプルデータで試す

`sample-data/` フォルダに6つのサンプルプロジェクトを用意しています：

1. 【順調】モバイルアプリ開発
2. 【炎上】レガシーシステム刷新
3. 【完了】社内ポータルサイト構築
4. 【アジャイル】AIチャットボット開発
5. 【小規模】社内ツール改善
6. 【大規模】基幹システム刷新プロジェクト

ヘッダーの「📥 インポート」からJSONファイルを読み込んで試せます。

## プライバシー

WBS Toolは完全にローカル動作します：
- データは全てブラウザのLocalStorageに保存されます
- サーバーへのデータ送信は一切ありません
- 外部APIへの接続もありません
- あなたのデータはあなたのブラウザにのみ保存されます

**重要**: ブラウザのキャッシュクリアでデータが消える可能性があるため、定期的にエクスポート機能でバックアップを取ることをお勧めします。
