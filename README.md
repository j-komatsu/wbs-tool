# WBS Tool

軽量で高性能なWeb Based Work Breakdown Structure & Agile Project Management ツール

## 概要

WBS Toolは、完全にブラウザ上で動作する静的Webアプリケーションです。サーバー不要で、ローカルストレージを活用してプロジェクト管理を行えます。

### 主な特徴

- 📊 **WBS & ガントチャート**: 階層的なタスク管理とビジュアルなスケジュール表示
- ⚡ **イナズマ線**: 進捗状況を一目で把握
- 🏃 **アジャイル/スクラム対応**: スプリント、バックログ、ストーリーポイント管理
- 📈 **豊富なチャート**: バーンダウン、バーンアップ、ベロシティ、CFDなど
- 📄 **自動レポート生成**: 進捗レポートをPDF/HTML/Markdownで出力
- 💾 **ローカルストレージ**: サーバー不要、データは全てブラウザに保存
- 📤 **インポート/エクスポート**: JSON、CSV、TSV形式に対応
- 🎨 **カスタマイズ可能**: テーマ、表示項目、スプリント設定など

## クイックスタート

1. リポジトリをクローンまたはダウンロード
```bash
git clone https://github.com/yourusername/wbs-tool.git
cd wbs-tool
```

2. ブラウザで `index.html` を開く
```bash
# シンプルなHTTPサーバーを起動（推奨）
npx http-server -p 8080
# または
python -m http.server 8080
```

3. ブラウザで `http://localhost:8080` にアクセス

## 使い方

### 基本操作

1. **新規タスク作成**: 「新規」ボタンをクリックまたは Ctrl+N
2. **タスク編集**: タスクをダブルクリック
3. **階層化**: タブキーでインデント、Shift+タブでアウトデント
4. **ドラッグ&ドロップ**: タスクをドラッグして並び替え・階層変更

### スプリント管理

1. **スプリント作成**: 設定メニューから「新規スプリント」
2. **タスク追加**: バックログからスプリントへドラッグ&ドロップ
3. **進捗確認**: ダッシュボードでバーンダウンチャートを確認

### データエクスポート

- **JSON**: 完全なプロジェクトデータ（バックアップ用）
- **CSV**: Excelで開ける形式
- **TSV**: タブ区切り形式
- **レポート**: PDF/HTML形式の進捗レポート
