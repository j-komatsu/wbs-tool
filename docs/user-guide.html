はじめに

WBS Toolは、ブラウザ上で動作する軽量なプロジェクト管理ツールです。サーバー不要で、すべてのデータはブラウザのLocalStorageに保存されます。

✨ 主な機能

  • タスクの作成・編集・削除
  • 階層的なタスク管理（最大10階層）
  • ガントチャート表示
  • 自動保存（3秒ごと）
  • 自動バックアップ（5分ごと）
  • データのインポート/エクスポート
  • 複数プロジェクト管理

動作環境

  • Google Chrome（推奨）
  • Mozilla Firefox
  • Microsoft Edge
  • Safari

基本操作

初回起動

  1. index.htmlをブラウザで開く
  2. サンプルプロジェクトが自動的に作成される
  3. 8個のサンプルタスクが表示される

タスク管理

タスクの作成

方法1: ボタンから作成

  1. 「📝 新規タスク」ボタンをクリック
  2. タスク情報を入力
  3. 「保存」をクリック

方法2: キーボードショートカット

Ctrl + N (Windows) / Cmd + N (Mac)

タスクの編集

タスク行をダブルクリックして編集モーダルを開く

入力項目

項目 説明 必須
タスク名 タスクの名称 ✅
種別 Epic / Story / Task / Bug
ステータス ToDo / 進行中 / レビュー / 完了
優先度 高 / 中 / 低
開始日 タスク開始予定日
終了日 タスク完了予定日
進捗率 0-100%
親タスク 親となるタスクを選択
ストーリーポイント 1,2,3,5,8,13,21,34
担当者 担当者名

タスクの階層化

親タスクの設定方法

  1. タスク編集モーダルを開く
  2. 「親タスク」ドロップダウンから親を選択
  3. 保存
ヒント: ドロップダウンは階層構造で表示されます。自分自身や自分の子孫は選択できません（循環参照防止）

階層の例

📦 Epic: プロジェクト計画
　├─ 📖 Story: 要件定義
　│　　├─ 📋 Task: ヒアリング
　│　　└─ 📋 Task: 要件書作成
　└─ 📖 Story: 基本設計

ガントチャート

基本表示

  • 左側: WBSリスト（タスク名、種別、ポイント、担当者など）
  • 右側: タイムラインとタスクバー

タスクバーの色

色 ステータス
灰色 ToDo
青色 進行中
黄色 レビュー
緑色 完了

タイムライン

  • 現在日: 青い縦線で表示
  • 週末: 薄い背景色
  • タスクバー: 開始日〜終了日の期間を表示
  • 進捗: タスクバー内の薄い色で表示

プロジェクト管理

新規プロジェクトの作成

  1. ヘッダー右上の「+」ボタンをクリック
  2. プロジェクト名を入力
  3. 新しい空のプロジェクトが作成される

プロジェクトの切り替え

  1. ヘッダーの「プロジェクト選択」ドロップダウンをクリック
  2. プロジェクトを選択

インポート/エクスポート

エクスポート

方法

  1. 「📤 エクスポート」ボタンをクリック
  2. 形式を選択：
    • 1: JSON（現在のプロジェクト）
    • 2: JSON（すべてのプロジェクト）
    • 3: CSV
    • 4: TSV

形式別の説明

形式 内容 用途
JSON（単体） 完全なプロジェクトデータ バックアップ、共有
JSON（全体） すべてのプロジェクトと設定 完全バックアップ、PC移行
CSV タスク一覧（Excel互換） レポート作成、Excel加工
TSV タスク一覧（タブ区切り） テキスト編集、他ツール連携

インポート

方法

  1. 「📥 インポート」ボタンをクリック
  2. ファイルを選択（JSON, CSV, TSV）
  3. 確認ダイアログで「OK」
⚠️ 注意:
  • JSONインポート（全体）: 既存データを上書きします
  • CSVインポート: 現在のプロジェクトのタスクをすべて置き換えます
  • バックアップを作成してから実行することを推奨します

キーボードショートカット

ショートカット 機能
Ctrl+N / Cmd+N 新規タスク作成
Ctrl+S / Cmd+S 手動保存
Esc モーダルを閉じる
Enter タスク編集（タスク選択時）
Delete タスク削除（タスク選択時）
ヒント: ショートカットは入力フィールド外で使用してください

トラブルシューティング

データが保存されない

原因: LocalStorageが無効、または容量超過

対策:

  1. ブラウザの設定でCookieを確認
  2. シークレットモードは使用しない
  3. 古いプロジェクトを削除
  4. データをエクスポートして新規プロジェクト作成

エクスポートしたCSVが文字化けする

原因: Excelの文字コード設定

対策:

  1. CSVをメモ帳で開く
  2. 「名前を付けて保存」→ エンコード「UTF-8」
  3. Excelで「データ」→「テキストファイル」からインポート

ガントチャートが表示されない

原因: タスクに開始日・終了日が設定されていない

対策:

  • タスク編集で日付を設定
  • サンプルプロジェクトで動作確認

定期的なバックアップ（推奨）

推奨頻度: 週1回
  1. 「エクスポート」→「2: すべてのプロジェクト」
  2. ファイルを保存（クラウドストレージ推奨）

FAQ

Q: オフラインで使えますか？

A: はい。完全にブラウザ内で動作します。ただし、初回ロード時はHTMLファイルへのアクセスが必要です。

Q: 複数人で共有できますか？

A: JSONエクスポート/インポートで手動共有可能です。リアルタイム共同編集は非対応です。

Q: スマホで使えますか？

A: 閲覧は可能ですが、編集機能は制限されます。PC・タブレット推奨です。

Q: データの保存先は？

A: ブラウザのLocalStorage（容量: 約5-10MB）。物理的な場所はブラウザ依存です。

Q: サーバーにデータは送信されますか？

A: いいえ。完全にローカルで動作します。
