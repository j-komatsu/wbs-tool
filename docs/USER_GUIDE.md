## はじめに

WBS Toolは、ブラウザ上で動作する軽量なプロジェクト管理ツールです。
サーバー不要で、すべてのデータはブラウザのLocalStorageに保存されます。

### 主な機能
- ✅ タスクの作成・編集・削除
- ✅ 階層的なタスク管理（最大10階層）
- ✅ ガントチャート表示
- ✅ 自動保存（3秒ごと）
- ✅ 自動バックアップ（5分ごと）
- ✅ データのインポート/エクスポート
- ✅ 複数プロジェクト管理

### 動作環境
- Google Chrome（推奨）
- Mozilla Firefox
- Microsoft Edge
- Safari

## 基本操作

### 初回起動

1. `index.html`をブラウザで開く
2. サンプルプロジェクトが自動的に作成される
3. 8個のサンプルタスクが表示される

### 画面構成

```
+--------------------------------------------------+
| ヘッダー: タイトル | プロジェクト選択 | 設定       |
+--------------------------------------------------+
| ビュータブ: ガントチャート | カンバン | ...       |
+--------------------------------------------------+
| ツールバー: 新規タスク | 保存 | エクスポート | ... |
+--------------------------------------------------+
| 検索・フィルター                                  |
+--------------------------------------------------+
| メインエリア:                                     |
|   - 左: WBSリスト（タスク一覧）                   |
|   - 右: ガントチャート                            |
+--------------------------------------------------+
| ステータスバー: 最終保存時刻 | タスク数            |
+--------------------------------------------------+
```

## タスク管理

### タスクの作成

**方法1: ボタンから作成**
1. 「📝 新規タスク」ボタンをクリック
2. タスク情報を入力
3. 「保存」をクリック

**方法2: キーボードショートカット**
- `Ctrl+N` (Windows) / `Cmd+N` (Mac)

### タスクの編集

**タスク行をダブルクリック**して編集モーダルを開く

#### 入力項目

| 項目 | 説明 | 必須 |
|------|------|------|
| タスク名 | タスクの名称 | ✅ |
| 種別 | Epic / Story / Task / Bug | |
| ステータス | ToDo / 進行中 / レビュー / 完了 | |
| 優先度 | 高 / 中 / 低 | |
| 開始日 | タスク開始予定日 | |
| 終了日 | タスク完了予定日 | |
| 進捗率 | 0-100% | |
| 親タスク | 親となるタスクを選択 | |
| ストーリーポイント | 1,2,3,5,8,13,21,34 | |
| 担当者 | 担当者名 | |
| 説明 | タスクの詳細説明 | |
| 受け入れ基準 | 完了条件 | |

### タスクの階層化

#### 親タスクの設定方法

1. タスク編集モーダルを開く
2. 「親タスク」ドロップダウンから親を選択
3. 保存

**ヒント:**
- ドロップダウンは階層構造で表示されます
- 自分自身や自分の子孫は選択できません（循環参照防止）

#### 階層の例

```
📦 Epic: プロジェクト計画
　├─ 📖 Story: 要件定義
　│　　├─ 📋 Task: ヒアリング
　│　　└─ 📋 Task: 要件書作成
　└─ 📖 Story: 基本設計
```

### タスクの展開/折りたたみ

- 親タスクの左側にある **▼** / **▶** ボタンをクリック
- 子タスクの表示/非表示を切り替え

### タスクの削除

1. タスク編集モーダルを開く
2. 「削除」ボタンをクリック
3. 確認ダイアログで「OK」

**注意:** 子タスクがある場合、すべて削除されます

## ガントチャート

### 基本表示

- 左側: WBSリスト（タスク名、種別、ポイント、担当者など）
- 右側: タイムラインとタスクバー

### タスクバーの色

| 色 | ステータス |
|----|-----------|
| 灰色 | ToDo |
| 青色 | 進行中 |
| 黄色 | レビュー |
| 緑色 | 完了 |

### タイムライン

- **現在日**: 青い縦線で表示
- **週末**: 薄い背景色
- **タスクバー**: 開始日〜終了日の期間を表示
- **進捗**: タスクバー内の薄い色で表示

### 表示期間の変更

現在は**日次表示**がデフォルトです。
（週次/月次表示は今後実装予定）

## プロジェクト管理

### 新規プロジェクトの作成

1. ヘッダー右上の「+」ボタンをクリック
2. プロジェクト名を入力
3. 新しい空のプロジェクトが作成される

### プロジェクトの切り替え

1. ヘッダーの「プロジェクト選択」ドロップダウンをクリック
2. プロジェクトを選択

### プロジェクトの削除

現在はUI未実装です。
開発者ツールで以下を実行：

```javascript

// プロジェクトを削除（IDを指定）
Storage.deleteProject('プロジェクトID')
```

## インポート/エクスポート

### エクスポート

#### 方法

1. 「📤 エクスポート」ボタンをクリック
2. 形式を選択：
   - `1`: JSON（現在のプロジェクト）
   - `2`: JSON（すべてのプロジェクト）
   - `3`: CSV
   - `4`: TSV

#### 形式別の説明

**JSON（プロジェクト単体）**
- 完全なプロジェクトデータ
- 再インポート可能
- 用途: バックアップ、他のユーザーとの共有

**JSON（すべてのプロジェクト）**
- すべてのプロジェクトと設定
- 用途: 完全バックアップ、別PCへの移行

**CSV**
- Excelで開ける形式
- タスク一覧のみ（階層情報含む）
- 用途: レポート作成、Excel加工

**TSV**
- タブ区切り形式
- 用途: テキストエディタでの編集、他ツール連携

### インポート

#### 方法

1. 「📥 インポート」ボタンをクリック
2. ファイルを選択（JSON, CSV, TSV）
3. 確認ダイアログで「OK」

#### 注意事項

**JSONインポート:**
- プロジェクト単体: 新しいプロジェクトとして追加
- 全プロジェクト: **既存データを上書き**（要注意！）
- 同じIDのプロジェクトがある場合は確認ダイアログ表示

**CSVインポート:**
- 現在のプロジェクトのタスクを**すべて置き換え**
- バックアップを作成してから実行推奨

### CSVフォーマット

#### ヘッダー行

```csv
ID,タスク名,種別,ステータス,優先度,開始日,終了日,進捗率,ストーリーポイント,担当者,説明,受け入れ基準,親タスクID,階層レベル
```

#### データ例

```csv
ID,タスク名,種別,ステータス,優先度,開始日,終了日,進捗率,ストーリーポイント,担当者,説明,受け入れ基準,親タスクID,階層レベル
uuid-001,プロジェクト計画,epic,in_progress,high,2024-01-01,2024-01-31,50,21,田中,"プロジェクト全体の計画","計画書完成",,0
uuid-002,要件定義,story,done,high,2024-01-01,2024-01-07,100,5,田中,"要件のヒアリングと文書化","要件書承認",uuid-001,1
```

## トラブルシューティング

### データが保存されない

**原因:** LocalStorageが無効、または容量超過

**対策:**
1. ブラウザの設定でCookieを確認
2. シークレットモードは使用しない
3. 古いプロジェクトを削除
4. データをエクスポートして新規プロジェクト作成

### ページリロード後にデータが消えた

**原因:** ブラウザのキャッシュクリア、シークレットモード

**対策:**
- 定期的にJSONエクスポートしてバックアップ
- 自動バックアップ機能（5分ごと）を確認

### エクスポートしたCSVが文字化けする

**原因:** Excelの文字コード設定

**対策:**
1. CSVをメモ帳で開く
2. 「名前を付けて保存」→ エンコード「UTF-8」
3. Excelで「データ」→「テキストファイル」からインポート

### ガントチャートが表示されない

**原因:** タスクに開始日・終了日が設定されていない

**対策:**
- タスク編集で日付を設定
- サンプルプロジェクトで動作確認

### エラーメッセージが表示された

**原因:** データ破損、ブラウザ互換性問題

**対策:**
1. ページをリロード（F5）
2. ブラウザのコンソールでエラー内容を確認
3. 別のブラウザで試す
4. 最悪の場合、LocalStorageをクリア:
   ```javascript
   localStorage.clear()
   ```
   **注意:** すべてのデータが消えます！

## ヒント＆ベストプラクティス

### 定期的なバックアップ

**推奨頻度:** 週1回

1. 「エクスポート」→「2: すべてのプロジェクト」
2. ファイルを保存（クラウドストレージ推奨）

### 階層構造の設計

**推奨:**
```
Epic（大機能）
└─ Story（ユーザーストーリー）
   └─ Task（実装タスク）
      └─ Sub-Task（細かい作業）
```

**最大10階層**まで可能ですが、**3-4階層**が管理しやすい

### ストーリーポイントの使い方

- フィボナッチ数列: 1,2,3,5,8,13,21...
- **相対的な見積もり**として使用
- 例:
  - 1pt = 数時間
  - 3pt = 半日〜1日
  - 8pt = 2-3日

### 担当者名の統一

CSVエクスポート時にフィルタリングしやすくするため、
**表記を統一**しましょう。

❌ 悪い例: 田中、Tanaka、たなか
✅ 良い例: 田中（統一）

## FAQ

### Q: オフラインで使えますか？

A: はい。完全にブラウザ内で動作します。
ただし、初回ロード時はHTMLファイルへのアクセスが必要です。

### Q: 複数人で共有できますか？

A: JSONエクスポート/インポートで手動共有可能です。
リアルタイム共同編集は非対応です。

### Q: スマホで使えますか？

A: 閲覧は可能ですが、編集機能は制限されます。
PC・タブレット推奨です。

### Q: データの保存先は？

A: ブラウザのLocalStorage（容量: 約5-10MB）
物理的な場所はブラウザ依存です。

### Q: サーバーにデータは送信されますか？

A: いいえ。完全にローカルで動作します。
