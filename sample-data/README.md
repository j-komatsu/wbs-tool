## インポート方法

### 個別プロジェクトのインポート
1. WBSツールを開く
2. 設定（⚙️）> データインポート
3. インポートしたいプロジェクトのJSONファイルを選択
4. 確認ダイアログで「はい」をクリック

### 全プロジェクト一括インポート
1. WBSツールを開く
2. 設定（⚙️）> データインポート
3. `00_全プロジェクト一括インポート.json` を選択
4. 確認ダイアログで「はい」をクリック
5. すべてのプロジェクトがインポートされます

## データ構造

各プロジェクトファイルには以下の情報が含まれます:

```json
{
  "id": "プロジェクトID",
  "name": "プロジェクト名",
  "description": "説明",
  "startDate": "開始日",
  "endDate": "終了日",
  "tasks": [
    {
      "id": "タスクID",
      "name": "タスク名",
      "type": "epic|story|task|bug",
      "status": "todo|in_progress|review|done",
      "startDate": "開始予定日",
      "endDate": "終了予定日",
      "actualStartDate": "実開始日",
      "actualEndDate": "実終了日",
      "assignee": "担当者",
      "storyPoints": "ストーリーポイント",
      "dependencies": ["依存タスクID"],
      "tags": ["タグ"],
      "description": "詳細説明",
      "progress": "進捗率",
      "parentId": "親タスクID",
      "sprintId": "スプリントID"
    }
  ],
  "sprints": [
    {
      "id": "スプリントID",
      "name": "スプリント名",
      "startDate": "開始日",
      "endDate": "終了日",
      "goal": "スプリントゴール",
      "status": "completed|active|planned"
    }
  ],
  "members": [
    {
      "id": "メンバーID",
      "name": "名前",
      "role": "役割",
      "email": "メールアドレス"
    }
  ]
}
```

## 注意事項

- インポートすると既存のプロジェクトに追加されます
- 同じIDのプロジェクトが存在する場合は上書き確認が表示されます
- データはブラウザのLocalStorageに保存されます
- ブラウザのキャッシュをクリアするとデータが消えます
- 定期的にエクスポートしてバックアップを取ることをおすすめします

## トラブルシューティング

### インポートエラーが発生する
- JSONファイルの形式が正しいか確認してください
- ファイルが破損していないか確認してください
- ブラウザのコンソールでエラー詳細を確認してください

### グラフが表示されない
- ページをリロードしてください
- ブラウザのキャッシュをクリアしてください

### データが表示されない
- プロジェクト選択ドロップダウンで正しいプロジェクトが選択されているか確認してください
- LocalStorageの容量が上限に達していないか確認してください
